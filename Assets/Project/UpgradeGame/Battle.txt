Сущности
RunState
Состояние текущего забега:
- номер уровня;
- текущая волна;
- HP базы;
- золото забега;
- выбранные временные усиления;
- открытые клетки;
- состояние: подготовка, бой, выбор карты, победа, поражение.
LevelConfig
Описание уровня:
- сколько волн;
- какие враги;
- где выдаются карты;
- есть ли босс;
- стартовое золото;
- стартовое HP базы;
- награда за победу.
WaveConfig
Описание волны:
- список врагов;
- количество;
- задержка между врагами;
- награда за волну;
- тип волны: обычная, усиленная, карта, босс.
Enemy
Враг:
- HP;
- скорость;
- урон по базе при проходе;
- награда за убийство;
- тип: обычный, быстрый, толстый, босс.
DefenseGrid
Сетка защитников:
- размер, например 5x3;
- какие клетки открыты;
- какие клетки закрыты;
- какие юниты стоят в клетках.
DefenseSlot
Одна клетка:
- открыта/закрыта;
- занята/пустая;
- какой юнит внутри;
- можно ли поставить;
- можно ли мержить.
DefenderUnit
Башня/юнит игрока:
- тип;
- уровень;
- урон;
- скорость атаки;
- дальность;
- особенность атаки.
MergeSystem
Правила мержа:
- одинаковый тип;
- одинаковый уровень;
- результат: тот же тип, уровень +1.
RunCard
Временное усиление:
- +урон;
- +скорость атаки;
- +дальность;
- +золото;
- +HP базы;
- ремонт базы;
- бесплатный юнит;
- усиление конкретного типа башен.
BattleReward
Награда:
- золото за волну;
- валюта за завершение уровня;
- сундук/ключ после босса, если понадобится позже.
       
Жизненный Цикл Забега
1. Игрок выбирает следующий уровень в линейке.
2. Создается RunState.
3. Загружается поле, сетка защитников, база, враги текущего уровня.
4. Начинается фаза подготовки.
5. Игрок покупает защитников, ставит их в сетку, мержит одинаковых.
6. Игрок запускает волну.
7. Враги начинают идти по пути.
8. Защитники автоматически атакуют врагов в радиусе.
9. Если враг умер, игрок получает награду за убийство.
10. Если враг дошел до конца пути, база получает урон, враг исчезает.
11. Если HP базы стало 0, забег проигран.
12. Если все враги волны закончились, волна пройдена.
13. Игрок получает награду за волну.
14. Если это ключевая волна, показываем выбор 1 из 3 карт забега.
15. Игрок выбирает карту, усиление применяется до конца забега.
16. Снова фаза подготовки.
17. Цикл повторяется до последней волны.
18. Последняя волна может быть боссом.
19. После победы игрок получает награду уровня.
20. Открывается следующий уровень в линейке.
